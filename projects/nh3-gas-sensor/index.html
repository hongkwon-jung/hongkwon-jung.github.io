상온 NH3 가스센서 소재 설계 및 감지 특성

산화물 반도체 CMOS 설계와 MXene, MBene 데코 용액공정 IZO 상온 가스센서 (캡스톤설계 1, 2)

처음 접한 분야에서 MBene을 직접 선정해 가열과 UV 없이 상온에서 NH3 1 ppm을 감지하고, 같은 IZO 위 MXene과 반대되는 소재별 선택성을 확인한 연구입니다.

01목표

요구 사양과 연구 방향

축사 부지경계의 NH3를 상시 감시하는 센서를 목표로, 악취방지법 시행규칙 별표 3의 기준(기타지역 1 ppm)에 맞춰 요구 사양을 정했습니다.

항목요구 사양
감지 농도NH3 1 ppm
응답 시간60초
회복 시간120초
동작 조건가열과 UV 없이 상온
02수행 내용

소재 선정과 합성

  • 선행 산화물·MBene 센서가 F 말단기로 NO2를 겨냥한 것과 달리, MBene의 OH 말단기로 NH3를 겨냥하는 방향과 소재 결정
  • MXene과 MBene을 식각 경로별로 3배치 합성하고 Stokes 식으로 침강 분리 조건 산출
  • 용액공정 IZO 채널 위에 MXene, MBene을 올린 센서 제작
03문제 해결

가스 측정 시스템 구축과 측정 신뢰성

측정 시스템 재셋업과 안전 검증

상황
오래 쓰지 않던 가스 측정 장비와 MFC로 NO2, NH3 같은 유독가스를 측정해야 함
확인
누출에 대비해 N2와 Air로 먼저 셋업하고 응답을 아는 MoS2 기준 소자로 검증. 가스를 바꿔도 저항이 변하지 않아 가스 공급 문제로 판단
조치
라인을 추적해 연결 순서 오류와 느슨한 이음부를 바로잡고, 그 이음부 쪽에 가스 검출기를 둔 뒤 유독가스 사용
결과
기준 소자의 정상 응답을 확인한 뒤 측정 시작

기판 누설 경로

상황
1차 측정에서 노이즈가 크고 저항이 불안정
확인
기판에 수에서 수백 MΩ의 누설 경로 확인. 정상은 개방
조치
기판 세정과 선별로 개방 상태 확보
결과
응답과 노이즈 분리

UV 조사 배제

상황
선행 연구는 UV를 함께 쓰는 경우가 많음
확인
UV를 켜면 저항이 1.96에서 1.42 kΩ로 떨어져 가스 응답이 묻힘
조치
UV 없이 측정하는 조건으로 결정
결과
가열과 UV 없이 1 ppm 응답 확인

소재 대조 실험

상황
NH3 응답이 MBene에서 나오는지, IZO 채널에서 나오는지 구분 필요
확인
같은 30초 노출에서 bare IZO는 NH3 1 ppm에 −0.26%, MBene/IZO는 +2.03%
결과
같은 IZO 위 MXene은 NO2에만, MBene은 NH3에 반응하는 소재별 선택성 확인

상온 NH3 감지 특성

05배운 점

배운 점

  1. 처음 접한 분야도 요구 사양과 소재의 표면 특성에서 출발하면 연구 방향을 정할 수 있음
  2. 새 측정 시스템의 결과는 기준 소자와 대조 소자로 장비와 소재의 기여를 분리한 뒤에 주장할 수 있음
