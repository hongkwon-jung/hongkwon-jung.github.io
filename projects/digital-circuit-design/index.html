MATERNITY SEAT

블루투스를 이용한 임산부 배려석

학기
2024-1
과목
기초회로실험및설계1
팀
5인
역할
팀장

임산부 배지가 작아 배려석 양보가 잘 이뤄지지 않는 문제에서 출발했습니다. 휴대폰을 블루투스로 배려석과 연결하면 좌석 아래 LED가 5초간 켜지고, 디스플레이에 한 칸의 임산부 인원 수가 표시되도록 설계했습니다.

구성역할
Arduino Uno, HC-05휴대폰 블루투스 연결 감지
NE555 단안정LED 5초 점등
7447, 7-segment임산부 인원 수 표시
논리 게이트좌석 신호 종합
네오픽셀 LED, 음성 모듈좌석 표시와 안내 음성

문제 해결

  • NE555의 trigger(2번)와 threshold(6번) 핀을 RC 회로에 함께 연결하고 논리 게이트로 LED를 구동해, 스위치 없이 5초만 자동 점등되는 회로로 변경
  • HC-06의 state 핀이 연결 상태를 제대로 출력하지 않아, state 핀으로 휴대폰 연결 여부를 읽을 수 있는 HC-05로 교체
  • Arduino 2개와 회로 전원을 따로 쓰자 오동작이 생겨 세 전원의 ground를 통일하고, 5 V를 안정적으로 주는 배터리로 전원 확보
SMART ELEVATOR

Smart Elevator

학기
2024-2
과목
기초회로실험및설계2
팀
5인
역할
팀장

4층 엘리베이터를 논리 IC로 구현했습니다. 현재층과 요구층을 비교해 상승, 정지, 하강을 결정하고, 상승 중에는 상승 요청을, 하강 중에는 하강 요청을 먼저 처리합니다.

  • 이동 시간과 문 개폐 시간을 고려해 층마다 처리 시간 부여
  • 버튼을 누른 뒤 1.5초 이상 자리를 비우면 적외선 센서로, 정원 초과 무게면 압력 센서로 요청 신호 차단
  • 예상 도착 시간을 계산해 7-segment로 표시(1층 기준)
  • 회로를 요구·현재층 종합, 방향, 다음 층(D 플립플롭 상태 천이), 예상 시간, 클럭·센서 파트로 나눠 설계

문제 해결

  • 현재층을 one-hot 코드로 저장해 전원 인가 시 1층만 preset해야 했는데, 1초 단안정으로는 회로가 안정되기 전에 preset이 풀려 1층 preset만 2초 단안정으로 바꿔 해결
  • 정지 신호의 1초 high가 플립플롭 클럭에 따라 일정하지 않아 NE555로 1초 고정
  • 예상 시간 다운 카운터가 0에서 멈추지 않고 9로 순환하고, 비동기 reset 특성 때문에 숫자가 건너뛰어 출력 9(1001) 검출 시 reset되도록 수정
  • 카운터 역전압으로 회로 전체 VCC가 2.5 – 3 V 떨어져 다이오드로 막고, 그로 인한 전압 저하는 함수 발생기의 1초 클럭으로 대체
PARKING SYSTEM

자동 주차 배정 시스템

학기
2025-1
과목
전자재료물성실험및설계1
팀
4인
역할
팀장

6칸 주차장(장애인 2, 일반 2, 전기차 1, 경차 1)에서 차종과 장애 여부의 6가지 경우에 우선순위를 정하고, 이동 중 빈자리 발생, 배정 자리 점유, 여름철 그늘 자리 같은 돌발 상황까지 처리하는 배정 시스템을 설계했습니다.

  • 시스템을 Controller(8상태 FSM)와 Datapath(9개 블록)로 나누고 ASMD 차트로 상태 전이를 정리해 파트 분담
  • 기본 동작을 Verilog로 먼저 구현해 공유하고, Verilog와 SPICE로 제작 전 동작 검증
  • 제안발표 지적(돌발 상황 부족)에 FAIL 신호와 현재 위치 기준 재탐색을 추가해 설계 확장

문제 해결

  • 구현 중 전압 강하는 파워서플라이 2채널과 AND 게이트로 해결
  • active-low 소자와 설계 극성의 불일치는 보완 회로로 해결
NAVIGATION

최단 시간 경로 내비게이션

학기
2025-2
과목
전자재료물성실험및설계2
팀
3인
역할
팀원

버스, 환승, 도보 경로 가운데 목적지까지 가장 빨리 도착하는 경로를 ASMD 기반 FSM과 데이터패스로 탐색하고 결정하는 시스템입니다.

  • Controller는 15개 상태를 one-hot으로 인코딩하고, 현위치는 16-bit one-hot(블록 0 – 15)으로 저장
  • 데이터패스의 카운터로 현위치에서 위아래를 동시에 탐색해 가장 가까운 정류장을 찾고, 그 정류장에 오는 버스의 도착 시간 비교
  • 버스만 타는 경로, 환승 경로, 전 구간 도보 경로의 총 소요 시간을 비교해 최단 경로를 고르고 경유 정류장과 도보 구간을 레지스터에 저장
  • 사고 시 버스에서 내려 경로를 재검색하고, 정체 시 버스 가중치를 정체 값으로 바꾸는 돌발 상황 처리

문제 해결

  • 브레드보드를 약 14개 쓰면서 전압 강하로 신호 레벨이 무너져 버퍼를 넣고 파워서플라이를 여러 대로 나눠 공급
  • 여러 클럭을 쓰자 신호 간 타이밍이 어긋나 버스, 사람, 지연의 클럭을 동기화하고 행동 상태에서만 클럭이 발생하도록 Controller 수정
  • 행동마다 상태를 따로 만들어 Controller가 지나치게 커져, 상태 안의 카운터로 소규모 Controller를 구성해 최적화
