01Objective

Formation Conditions of the Gaussian Response

가우시안(anti-ambipolar) 트랜지스터는 특정 게이트 전압 구간에서만 전류가 흐르는 소자입니다.

목표: p형 WSe2/n형 IGZO 이종접합에서 이 응답이 생기는 조건을 밝히고 구조 변수별 영향을 정량화

ComponentReference structure
Gate / dielectricp++ Si back gate / Al2O3 90 nm
ChannelsIGZO 10 nm, WSe2 5 nm (8 layers)
ElectrodesAl (IGZO side), Pd (WSe2 side)
BiasVDS = 1 V

03Troubleshooting

Simulation Troubleshooting and Automation

Convergence failure

Situation
게이트 누설 모델 추가 후 +0.3 V에서 계산 중단
Diagnosis
로그에서 콘택 가장자리 전자 밀도가 0으로 무너지는 지점 확인
Action
그 모서리 메쉬만 수정
Result
+10 V까지 완주

Simulation time

Situation
1회 13시간
Diagnosis
행렬 조립 시간이 풀이 시간의 43배
Action
반복 계산 설정 조정
Result
6시간으로 단축

Mechanism verification

Situation
peak 전류의 출처가 SRH 재결합인지 캐리어 중첩인지 구분 필요
Diagnosis
SRH 수명 100배 변화에도 peak 전류 변화 0.03% 미만
Action
계면 트랩 밀도를 바꿔도 결론 유지 확인
Result
n·p 동시 도통과 WSe2 쪽 캐리어 중첩이 응답을 결정한다는 해석으로 게재

Fitting automation

Situation
모델 재설계마다 수동 피팅 약 2개월
Action
근거 조사·감도 계산·조건 설계·실행·판정·감사의 6역할 AI 파이프라인 구축. 물리 모델과 구간별 우선 특성은 직접 결정
Result
IGZO 피팅 39회 중 31회 수렴
04Results

Response Mechanism and Design Guidelines

Mechanism

peak 전류는 단일 채널 turn-on이나 두 전류의 합이 아니라 n·p 채널의 동시 도통과 WSe2 쪽 캐리어 중첩이 결정합니다.

05Lessons

Lessons

  1. 수많은 모델 변수는 고정할 것과 조정할 것을 나눠야 실측 특성을 지배하는 물리와 구조 변수의 영향을 구분할 수 있음
  2. 참고 자료 없이 익힌 새 도구도 원리를 세운 뒤에는 반복 작업을 자동화해 검증 주기를 줄일 수 있음
