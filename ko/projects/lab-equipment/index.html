02Troubleshooting

Problem, Cause, Action

E-beam cooling-water leak

Situation
공용 e-beam evaporator에서 냉각수가 챔버로 새어 장비가 멈춤
Diagnosis
엔지니어가 오기 전까지 칠러 연결부를 분해 점검해 누수 위치를 좁히고, 엔지니어와 함께 냉각수 유로를 밀봉하는 O-ring의 열 손상과 조치되지 않은 채 남아 있던 기존 칠러 손상을 근본 원인으로 확인
Action
O-ring 교체
Result
수리 시간 단축

E-beam vacuum leak

Situation
고진공 도달에 6시간 이상
Diagnosis
연결부마다 아세톤을 소량 바르며 진공 게이지 변화를 추적해 메인 챔버와 로터리 펌프 접합부의 체결 불량 특정
Action
접합부 재체결
Result
고진공 도달 6시간 이상 → 약 1.5시간, 같은 수리의 셋업으로 rate 상한 0.7 – 0.8 → 1.5 Å/s

Hot-plate temperature deviation

Situation
같은 설정 온도에서 결과가 다름
Diagnosis
모두 같은 온도로 설정한 뒤 핫플레이트별 실제 온도 편차 측정
Action
편차가 가장 작은 것은 soft-bake, 회전이 정상인 것은 용액 교반, 나머지는 hard bake에 배정하고 유기용과 무기용 분리

Gas measurement system re-setup

Situation
오래 쓰지 않던 가스 장비·MFC로 유독가스(NO2, NH3) 측정 필요
Diagnosis
MoS2 기준 소자 무응답. N2 인가 시 챔버의 산소 농도 저하 경보기가 울리지 않았고 MFC 지시 유량은 정상이어서, 누설 구간을 MFC와 챔버 사이로 좁힘
Action
누설 검지액 기포관찰법으로 누설 이음부를 특정해 정비, 라인 연결 순서 수정, 유독가스 사용 시 이음부에 가스 검출기 설치
Result
기준 소자 정상 응답 확인 후 측정 시작

E-beam chamber condensation

Situation
공정실 에어컨 고장으로 습도가 높던 시기, 4시간 넘게 펌핑해도 10−5 Torr 아래로 내려가지 않음
Diagnosis
칠러를 켠 채 벤트·로딩하는 동안 차가운 내벽에 맺히는 수분 의심
Action
빔이 없는 벤트·로딩·펌핑 동안 칠러를 끄고 증착 때만 켜도록 운전 순서 변경
Result
부품 교체 없이 정상 펌핑과 증착

E-beam rate readout

Situation
증착 rate 표시가 크게 흔들림
Diagnosis
전류, 전압, 진공도, 크루서블 위치, 빔 초점과 위치, 칠러 온도 정상, 평소 전류·전압에서 시간 대비 쌓인 두께가 이전과 비슷
Action
센서 오류로 판단하고 시간과 누적 두께로 증착 완료
Result
이후 점검에서 센서 오류로 확인
03Lessons

Lessons

  1. 장비 표시값은 시간 대비 두께, 실측 온도처럼 독립된 지표와 교차 확인한 뒤 믿어야 함
  2. 운전 순서는 각 부품의 목적을 해치지 않는 범위에서 바꿔야 함(빔이 켜진 동안 냉각 유지)
  3. 누설 검사는 압력 조건에 맞춰 골라야 함(진공 챔버는 연결부 아세톤 추적, 양압 가스 라인은 기포관찰법)
